# NHANES v1.4.8 reproduction r1: public access

Version date: 18 September 2026. The code and aggregate outputs are supplied in the ZIP in this directory; the separate participant-indexed local audit archive is not uploaded. Raw public data are downloaded from CDC using the included SHA256-checked downloader.

## Reproduce

Extract the ZIP, install Python 3.9+ and R 4.6.1 with the pinned packages in `docs/ENVIRONMENT.md`, and run:

```text
python code/run_all.py --out NEW_OUTPUT_DIRECTORY --rscript PATH_TO_RSCRIPT --lib PATH_TO_R_LIBRARY
```

The output directory must not exist. Omit --lib or --rscript if the correct runtime is already on the normal search path. All computation starts from four NHANES XPT files. Expected aggregate outputs are read only after model fitting and other calculations. The run generates full audit objects locally.

## Availability statement

The NHANES 2009–2010 public-use files DEMO_F, ARQ_F, DPQ_F and PAQ_F are available from CDC/NCHS. Study-specific processing instructions, analysis code, environment specifications, aggregate outputs and computational reproduction evidence are publicly available in the `Linrong726/research-sharing` GitHub repository, version `v1.4.8-reproduction-r1`. Use the verified fixed-commit link in `SHARING_VERIFIED.json` when that receipt is added; the ZIP SHA256 is `f8422f82571fe0698ea11a4010c95ec4bac8016290ac22bbbeb7c5a3583d1e41`. Individual-level audit objects are retained separately and can be regenerated by running the code. No DOI has been assigned.

## Evidence and limits

All four original adjusted analyses and the unadjusted/descriptive sources were recalculated. Historical adjusted estimates, replicates, covariance matrices and intervals matched exactly. One fixed post hoc quadratic age/PIR model gave Delta 9.2290 percentage points (95% CI -15.3545 to 33.8125); the primary Delta remained 8.7014 (-7.4922 to 24.8950). Neither interval excludes zero. Support limitations remain. Computational reproduction is not causal validation or proof of confidence-interval coverage.
